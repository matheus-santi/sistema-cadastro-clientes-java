
# Sistema de Cadastro de Clientes em Java

Projeto desenvolvido em Java com o objetivo de praticar lógica de programação, organização de código e manipulação de arquivos.

O sistema funciona via console e permite realizar operações básicas de um CRUD (Create, Read, Update, Delete).

---

## 🎯 Objetivo do Projeto

- Aprender Java na prática
- Trabalhar com menus interativos
- Manipular arquivos para persistência de dados
- Criar um projeto organizado para portfólio no GitHub

---

## ⚙️ Funcionalidades

- Cadastrar cliente
- Listar clientes cadastrados
- Editar dados de um cliente
- Remover cliente
- Salvar dados em arquivo `.txt`
- Carregar dados ao iniciar o sistema
